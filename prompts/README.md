# Implementation Prompts

This directory contains implementation plans generated by the AI coding agent before feature work.

## Required workflow

For a development request, the agent:

1. Reads `AGENTS.md` and the relevant `context/` files.
2. Inspects the existing code.
3. Creates a focused prompt file here.
4. Requests approval when the task has not explicitly authorized execution.
5. Implements only the approved scope.
6. Runs verification.
7. Updates the progress tracker.

## Prompt naming

Use:

```
<feature-number>-<short-feature-name>.md
```

Examples:

- `08-customer-feedback-ux.md`
- `09-admin-dashboard.md`
- `10-google-reply-publication.md`

Do not store secrets, credentials, or temporary chat transcripts in this directory.

Prompt files are implementation plans. Durable product and architecture decisions belong in `context/`.
